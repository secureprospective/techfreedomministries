# TFM_03 — THE FOUR-LEVEL ROADMAP
*The member journey. The ladder. The thing that turns an event into a movement.*

---

## Overview

The Roadmap is the backbone of TFM's retention system. It transforms a one-time event into an ongoing identity. Members do not "attend TFM" — they are *on the Roadmap*. That framing matters.

The physical Roadmap card (printed on heavy cardstock) is handed to every Install Party graduate. Checking a physical box with a pen creates a psychological commitment that a digital progress bar cannot replicate.

For physical card specifications (size, stock, print, corner brackets), see TFM_08_DESIGN_SYSTEM.md.

---

## The Four Levels

---

### Level 1 — THE EXODUS (Beginner)
*Goal: Leave the plantation and establish your own dwelling.*

| | Milestone |
|---|---|
| ☐ | **The Clean Break** — Successfully installed Linux, previous proprietary OS wiped or dual-booted |
| ☐ | **The Driver Conquest** — Wi-Fi, sound, and display working after initial hurdles |
| ☐ | **The Tool Swap** — Replaced Big Tech apps with open source alternatives (LibreOffice, Firefox/Brave, VLC) |
| ☐ | **The Update Ritual** — Can update and maintain the system via Software Manager |
| ☐ | **The First Week** — Used Linux as primary machine for 7 straight days without reverting |

**Level 1 complete = Install Party graduate. Receives Roadmap card.**

---

### Level 2 — THE CATECHISM (Intermediate)
*Goal: Learn the language of the machine — the Terminal.*

| | Milestone |
|---|---|
| ☐ | **The Basic Commands** — Can navigate folders (cd, ls) and move files (mv, cp) without a mouse |
| ☐ | **Root Authority** — Understands what `sudo` means and when to use it carefully |
| ☐ | **The Package Master** — Can install software from the terminal (`sudo apt install`) |
| ☐ | **The Permission Slip** — Understands file permissions (chmod) and ownership |
| ☐ | **The Scripting Spark** — Has run or written a simple `.sh` script to automate a task |

**Level 2 complete = eligible to attend Workshop Series: Homestead track.**

---

### Level 3 — THE HOMESTEAD (Power User)
*Goal: Independence from the cloud and corporate servers.*

| | Milestone |
|---|---|
| ☐ | **The Hardware Sovereign** — Can troubleshoot own hardware, understands system specs |
| ☐ | **The Local Backup** — Has physical backup of data they control (not corporate cloud) |
| ☐ | **The Self-Host Pilot** — Running at least one local service (Pi-Hole, Nextcloud, local file share) |
| ☐ | **The Hardened Heart** — Audited privacy settings, disabled unnecessary telemetry |
| ☐ | **The Daily Driver** — No longer relies on any Microsoft, Apple, or Google desktop software |

**Level 3 complete = eligible to apply for Vanguard status.**

---

### Level 4 — THE GREAT COMMISSION (Mentor / Vanguard)
*Goal: Replicating freedom in others.*

| | Milestone |
|---|---|
| ☐ | **The Translator** — Can explain the "why" of TFM (Galatians 5:1) to a non-technical person |
| ☐ | **The Guide** — Has successfully helped one other person through their first Install Party |
| ☐ | **The Trouble-Shooter** — Can help a newcomer fix a black screen or Wi-Fi driver issue |
| ☐ | **The Community Pillar** — Active in a local or digital forum helping others stay free |
| ☐ | **The Master Steward** — No longer a consumer of tech — a creator and protector of digital liberty |

**Level 4 complete = Freeman status. Credential card issued. Name on the wall.**

> *"When you have completed this map, you are no longer a student. You are a Freeman. Go and set others free."*

## The FOSS Equivalents Reference (Level 1 Quick Sheet)

| Old Tool | New Tool | Why |
|---|---|---|
| Windows / macOS | Linux Mint / Fedora | Speed, privacy, no forced updates |
| Google Chrome | LibreWolf / Brave | Blocks trackers, saves battery |
| Microsoft Office | LibreOffice | Open formats you actually own |
| Gmail / Outlook | Thunderbird | Email lives on your machine, not their server |
| Google Drive | Nextcloud (self-hosted) | Your cloud, your rules |
| Google Photos | Immich (self-hosted) | Your photos, your server |
| LastPass / 1Password | Bitwarden / Vaultwarden | Open source, self-hostable |

## The Roadmap as a Marketing Tool

When a member pulls out their card at a coffee shop or church, people ask what it is. That conversation — unprompted, human, specific — is worth more than any paid advertisement. Design the card to be worth keeping. Make it look like something you earned.
